# AD Sentinel

広告の**文面**を [TypeSafe jev](https://typesafe.ai) で判定し、**詐欺・偽警告・個人情報の要求・誇大表示・子供に不適切な表現の疑いが高い広告だけ**をぼかす Chrome 拡張機能です。文面に問題のない広告はそのまま表示しますが、画面をふさぐ広告(下表)は文面にかかわらず止めます。止める種類は設定画面で選べます(初期設定ではすべて有効)。

| 普通の広告 | 悪質の疑いが高い広告 | 画面をふさぐ広告 |
|---|---|---|
| そのまま表示 | ぼかして理由(例: 偽の警告・当選通知 91%)を表示。「表示する」で見られる | 全画面広告・広告の視聴を求める表示・画面に貼り付く広告・動画広告は消し、音声付き自動再生は消音して止める |

## 仕組み

- 各ページの content script が広告候補を検出します(既知の広告枠 /「PR」「広告」表記 / 広告配信ドメインの iframe)。既知の広告枠は判定が終わるまで CSS でぼかしておけます
- 画面に近づいた広告から、文面(最大600文字)・リンク先の「ドメイン/パス」・HTML の特徴(入力欄の種類・カウントダウン等)を取り出し、jev に 6 問(広告か / 詐欺 / 偽警告 / 個人情報要求 / 誇大表示 / 子供に不適切な表現)を並列で質問します
- 確率 × しきい値で「隠す / 注意 / 問題なし」を決めます。しきい値やカテゴリは設定で調整できます
- これと並行して、画面をふさぐ広告(全画面・貼り付き・動画広告・音声付き自動再生)は端末内のルールだけで即座に止めます(この検出はどこにも送信しません)
- 同じ文面の広告は 7 日間キャッシュし、再判定しません。判定の失敗時はぼかしを外して通常表示に戻します(ページを壊さないことを優先)

## インストール

Chrome ウェブストアでの公開は準備中です。それまでは次の手順でインストールできます。

### リリースの ZIP から

1. [Releases](https://github.com/HiroakiIchimaru/ad-sentinel/releases) から `ad-sentinel-v<version>.zip` をダウンロードし、任意のフォルダに**展開**する(展開したフォルダは削除せずに残してください)
2. Chrome で `chrome://extensions` を開き、右上の「**デベロッパー モード**」をオンにする
3. 「**パッケージ化されていない拡張機能を読み込む**」で、展開したフォルダを選ぶ
4. 設定画面が開くので、TypeSafe の APIキーを入力して「保存」→「接続テスト」(取得方法は次項)

### ソースからビルドする場合

```bash
npm install
```

```bash
npm run build
```

その後、上の手順 2〜4 で `dist/` フォルダを読み込んでください。

## APIキーの取得

判定には TypeSafe の APIキーが必要です(利用者ごとに自分のキーを使います)。キーを入れるまでは**簡易判定**(固定キーワード照合)で動きますが、文の意味を理解しないので実際の精度の目安にはなりません。簡易判定でも広告を隠すため、「FX」「配当」「LINE登録」のような語が並ぶだけで、正規の広告が「詐欺」として隠れることがあります。

1. [typesafe.ai](https://typesafe.ai) の「Sign Up」からアカウントを作成する
2. [コンソールの API Keys](https://console.typesafe.ai/keys) で APIキーを発行する
3. 拡張機能の設定画面(ツールバーのアイコン →「設定」)にキーを貼り付けて「保存」→「接続テスト」

料金の目安: jev の入力は $0.042/100万トークン・出力は無料。1 広告の判定は質問文を含めて約 1,400 トークン ≈ $0.00005(開発中の実測: 601 回で 822,813 トークン・$0.0321)なので、**1 日 1,000 広告を判定しても 1 日あたり約 8 円**です。TypeSafe のコンソールで支出上限を設定しておくと安心です。

キーは `chrome.storage.local`(拡張機能内のみ・Web ページから読めない設定)に保存され、`api.typesafe.ai` への判定リクエスト以外には使われません。

## 使い方

- ツールバーのアイコンで、そのページの判定一覧が見られます。一覧の番号はページ上の広告にも表示され、行をクリックするとその広告へ移動します。「表示」「隠す」で個別に切り替えられます
- 「判定の強さ」(控えめ / 標準 / 強め)と「表示方法」(ぼかす / 隠す / ラベルのみ)は popup から、しきい値・カテゴリ・画面妨害ブロックの種類・無効にするサイトは設定画面から変えられます
- 画面をふさぐ広告を止めたときは画面下に知らせが出て、「元に戻す」で戻せます

## 送信される情報

| jev に送る | 送らない |
|---|---|
| 広告と判定した要素内の文字(最大600文字)、画像の代替テキスト | 閲覧中のページの URL・タイトル・記事本文 |
| 広告のリンク先の「ドメイン/パス」(先頭2段まで。クエリと ID らしき部分は除く) | 入力欄・テキストエリア・編集可能領域の**値** |
| 広告の HTML の特徴(許可した6種類のみ。英語の説明文に置き換えて送る) | 広告の HTML そのもの、Cookie、閲覧履歴、あなたを識別する情報 |

- 画面をふさぐ広告の検出は端末内だけで行い、どこにも送信しません
- 判定一覧(広告文の冒頭60文字)は `chrome.storage.session` にだけ置き、ブラウザを閉じると消えます
- 通信には IP アドレスが伴い、「どんな広告が表示されたか」は TypeSafe に届きます
- 送った内容の TypeSafe での取り扱いは [TypeSafe のプライバシーポリシー](https://typesafe.ai/legal/privacy-policy) を参照してください

## 制限

- **判定は自動で、誤ることがあります**。正規の広告が隠れることも、悪質な広告を見逃すこともあります。表示される理由と確率(例: 詐欺・投資勧誘 78%)は疑いの強さの目安で、その広告や広告主が実際に詐欺などであることを示すものではありません
- **画像・動画の中の文字は読めません**(jev はテキスト専用)。画像だけの広告は「読取不可」として数えます
- 広告枠の検出は、既知のセレクタと「PR」「広告」等の表記に頼っています。検出できない広告もあります
- 画面妨害の自動ブロックは、広告枠・広告フレームとその入れ物だけが対象です。広告と分からない要素が画面を覆っても止めません(サイト自体のダイアログを壊さないため)
- ポップアップウィンドウ・勝手な画面遷移・戻るボタンの乗っ取りは対象外です
- 記事の動画プレーヤーの前後に流れる広告(プレロール)は、記事の動画ごと消してしまうので対象外です
- 有料会員・ログインの案内(ペイウォール)、広告ブロッカーへの警告、Cookie 等の同意画面は、サイトの利用条件に関わるので止めません
- 広告を一律に消す機能はありません。既存の広告ブロッカーと併用できます

## 開発

```bash
npm run typecheck   # 型チェック
npm test            # 単体テスト(Vitest + happy-dom)
npm run build       # dist/ に拡張機能を出力
npm run pack        # 提出・配布用の ZIP を生成
```

```
src/
  shared/      型、jev への質問定義、判定ロジック、設定
  background/  jev クライアント、キャッシュ、同時実行制御、タブ別の状態
  content/     広告の検出・判定材料の抽出・画面妨害の検出・表示(Shadow DOM)
  popup/       ツールバーの画面
  options/     設定画面
static/        manifest.json、HTML、CSS、アイコン
scripts/       ビルド、アイコン生成、パッケージ化
```
