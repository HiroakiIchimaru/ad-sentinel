AD Sentinel

広告の文面を jev で判定し、詐欺・偽警告・個人情報の要求・誇大表示・子供に不適切な表現の疑いが高い広告だけをぼかします。文面に問題のない広告はそのまま表示しますが、画面をふさぐ広告は下の設定に従って止めます。

判定エンジン(jev)

TypeSafe の APIキーを入力すると jev で判定します。未入力のあいだは簡易判定(固定キーワードの照合)で動きます。簡易判定は文の意味を理解しないため、正規の広告を隠すことがあります。

入力したキーはこのブラウザの拡張機能ストレージ(chrome.storage.local)にだけ保存され、 api.typesafe.ai への判定リクエスト以外には使いません。Web ページ側のスクリプトからは読めません。

判定

確率がしきい値以上の広告を隠します。誤って隠れる広告が多いときはしきい値を上げ、見逃しが多いときは下げてください。判定は自動のため誤ることがあり、確率は疑いの強さの目安です(広告主が実際に詐欺などであることを示すものではありません)。

対象にするカテゴリ

表示

画面をふさぐ広告の自動ブロック

文面の判定(jev)とは別に、広告の動作を端末内で調べて即座に止めます。対象は広告枠・広告フレームとその入れ物だけで、サイト自体のヘッダーやダイアログには触れません。

無効にするサイト

1行に1つ。サブドメインも対象になります(例: example.com)。popup からも切り替えられます。

送信される情報

jev に送るもの送らないもの
広告と判定した要素内の文字(最大600文字)・画像の代替テキスト閲覧中のページの URL・タイトル・記事本文
広告のリンク先の「ドメイン/パス」(先頭2段まで。クエリと ID らしき部分は除く)入力欄・テキストエリア・編集可能領域の値
広告の HTML の特徴(パスワード欄・カード番号欄・個人情報欄がある、カウントダウン、新しいウィンドウで開く、自動再生)広告の HTML そのもの(クリック計測 ID などを含むため)
Cookie・閲覧履歴・あなたを識別する情報

画面に近づいた広告だけを判定します。同じ文面の広告は7日間キャッシュ(文面のハッシュと確率のみ保存)し、再送信しません。 通信には通常どおり IP アドレスが伴い、「どんな広告が表示されたか」は TypeSafe に届きます。 送った内容の TypeSafe での取り扱いは TypeSafe のプライバシーポリシーをご覧ください。
